# zachellerbrook.com

Source for my personal site: portfolio front, blog behind. Static HTML and CSS, no framework.

I'm a Navy musician moving into cybersecurity. The site exists to show the work rather than describe it, so this repo is part of the portfolio too. Built in the open, in small commits, over time.
